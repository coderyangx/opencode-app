TopBar 中 ModelSelect 组件和设置按钮均被注释（{/* TODO 模型选择 */}，{/* TODO 系统提示词设置面板 */}）。作为 AI 助手产品，多模型切换是基础体验，当前所有用户只能使用默认的 gpt-5.4-mini。

【P1】上下文压缩未启用，长对话有 token 超限风险

chat.ts 第 54 行 compactMessages() 调用被注释。长对话（数十轮）会将全量历史发给模型，可能触发 context window 超限错误或产生高额 token 费用。

【P1】Supabase RLS 未开启，依赖业务层隔离

schema.sql 注释明确说明「关闭 RLS，用户隔离由 Worker 业务代码保证」。若 Worker 鉴权中间件出现 bug，用户可能读取他人数据。面向公众发布前应开启 Row Level Security。

🌐

【P1】CORS 开放了所有来源（origin: '*'）

worker/index.ts:41 中 cors 设置为 origin: '*'，任意域名都可跨域调用 API。应限制为 FRONTEND_URL（已在 vars 中配置，未使用）。

【P1】无注册速率限制，任何人可无限注册消耗 API 额度

邮件验证已关闭，任何人可批量注册账户无限调用 AI API。公开发布前需添加注册邀请码机制，或 Cloudflare Rate Limiting（每 IP 每小时注册上限）。
