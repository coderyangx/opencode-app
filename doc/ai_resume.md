### 前端工程化与性能稳定性建设

2023.10 - 2025.12 | Web 首屏性能、性能卡控工具、表单引擎告警治理

- 独立承担审批中心 Web 首屏性能治理，基于 Bundle Analyze、Lighthouse、慢访问分析与横向系统对比定位资源体积、接口串行、重复请求与表格渲染等瓶颈。
- 通过 Webpack 拆包、公共依赖抽离、组件按需引入、Lodash 按需优化、接口并行与请求时机调整，将 PC 端 parsed 体积由 9.31MB 降至 4.07MB，gzip 体积由 2.46MB 降至 1.09MB，本地首屏均值由约 2900ms 降至约 2100ms，首屏 TP90 达成 2600ms 内目标。
- 从 0 到 1 建设低代码平台线下性能卡控工具，基于 Puppeteer 覆盖首屏时间、FPS、卡顿帧、内存占用等指标，抽象 14 类测试场景与 5 档组件数量梯度，形成 130 个测试用例。
- 深入分析 dob 响应式框架源码，定量推导不同组件类型对 reaction 数量的影响，为设计器组件上限和性能预算提供依据；工具持续运营 5 个迭代并沉淀性能卡控 SOP，提前发现多起上线前性能风险。
- 建立表单引擎“异常告警 -> 根因分类 -> 修复治理 -> 增量监控”稳定性治理链路，清理存量异常并完成告警降噪，2025 年千行代码 bug 率约 0.278‰。
